# PREVIEW-011 Refuse only the preview security boundary and admit the remaining Mermaid syntax

- **status**: completed
- **priority**: P1
- **owner**: Frontend maintainer
- **createdAt**: 2026-09-12

## Description

The project owner reviewed an inventory of what the preview policy still refuses and decided that only the security boundary stays refused: configuration directives and configuration beyond the bounded front matter, interactive links and callbacks, HTML tags in text, HTML entities and Mermaid escape codes, resource and style injection (`](`, `url(`, `@import`, `expression(`, `linkStyle`), `@{}` metadata and math. Everything else the inventory listed is to be admitted. Acceptance: every construct in the boundary stays refused in every diagram family, including in titles and comment bodies where it applies; the constructs the inventory recorded as collateral refusals render; styling statements in every family take one bounded declaration check; and Mermaid still receives the original source.

## ActiveForm

Narrowing the preview policy to its security boundary.

- **blocks**: (none)

## Notes

- Investigation (2026-09-12, `main` at `8ef2d04`, release v0.8.2): 107 common constructs were measured against the real `validateSource` and the real `mermaid.parse` at the pinned 11.17.2. 67 are valid Mermaid that the policy refuses. They fall into the owner's boundary (directives, front matter beyond the bounded shape, `click`/`link`/`links` statements, HTML tags, entities, Mermaid escapes, `](`, `$$`, `@{}`, `linkStyle`) and into collateral refusals: any `<` outside flowchart carve-outs (class relations `<|--` and `<..`, `<<interface>>`, state `<<choice>>` and `<<fork>>`, comparisons in messages and titles); any `&` outside flowcharts; the words `style`, `css`, `links`, `click` and `href` anywhere in text; addresses outside whole-line comments, flowchart node labels and sequence notes; any backslash; declarations beyond five properties and three- or six-digit hex; `classDef` and `style` outside flowcharts; and lowercase placeholders.
- Investigation (2026-09-12): the collateral comes from the model, not from individual rules. The policy denies whole character classes and words across the source and then masks per-family exceptions, so every family whose ordinary syntax uses `<`, `&` or one of those words collides with it. The boundary, by contrast, is a short list of specific constructs.
- Investigation (2026-09-12): statement forms that parse under the pinned Mermaid: sequence `link`, `links`, `properties` and `details`, with `;` separating statements; class `click ... href`, `click ... call`, `callback`, `link`, `cssClass`, `classDef`, `style` and `:::`; state `classDef`, `class`, `style` and `:::` (no `click`); ER `style`, `classDef`, `class` and `:::`; Gantt `click ... href` and `click ... call`; block and requirement `style`, `classDef` and `class`; quadrant `classDef` with `radius` and `stroke-color`; treemap `classDef` and `:::`; mindmap `:::`; C4 `$link`, `$sprite` and `UpdateElementStyle`; Gantt `todayMarker` carrying raw CSS; flowchart `click` after `;`. In a class diagram, `class X` declares a class rather than assigning a style.
- Investigation (2026-09-12): HTML tokenization opens a tag only when `<` is immediately followed by an ASCII letter, `/`, `!` or `?`. Every other `<` is text to every conforming parser, and the render pipeline contains only conforming parsers: Mermaid writes SVG text with HTML labels disabled, DOMPurify parses per specification, and the sanitized SVG is re-read by `DOMParser` as XML.
- Investigation (2026-09-12): the service sends `default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'; form-action 'self'`. Inline event handlers cannot run and no external image, font or connection can load, independently of the source policy. This bounds the consequence of a construct the policy might fail to enumerate; it does not replace the boundary.
- Investigation (2026-09-12): a backslash matters in two places. YAML double-quoted scalars decode escapes, so a front matter title could spell a tag the text check never sees. CSS reads `\75 rl(` as `url(`, so a raw CSS value (Gantt `todayMarker`, sequence `box` and `rect` colours, C4 `$param=` values, quadrant point styles) could spell a resource the check never sees. Elsewhere a backslash is inert text.
- Investigation (2026-09-12): preview label editing re-runs `validateSource` on the edited source, so it inherits the policy; only its refusal message names keywords that would no longer be refused.
- Investigation (2026-09-12): the authoring environment cannot start the installed Chromium headless shell and pins a different Node, so browser and `check:ci` evidence will come from the hosted verify run. (Superseded the same day: Chromium's system libraries were installed as the README describes, so the browser suite now runs locally too.)
- Approval (2026-09-12): the owner approved PLAN-025 and asked for the preview size limits to change as well. Measured Mermaid alone in Chromium on eight cores: a flowchart of 500 edges in 0.9 s, 1,000 in 2.0 s, 2,000 in 5.8 s, 3,000 in 11.6 s and 5,000 in 39 s; a sequence diagram of 1,500 messages and about 98,000 characters in 0.7 s. The limits became 100,000 characters and 1,000 edges.
- Implementation (2026-09-12): `source-policy.ts` was rewritten around the boundary. One expression refuses directives, entities and Mermaid escapes, Markdown links and images, `url(`, `image-set(`, `@import`, `expression(`, `javascript:`, `vbscript:`, `@{` and `$$` across the whole source; C4 `$link` and `$sprite` parameters and control characters join it; a tokenizer-shaped check refuses a `<` immediately followed by `/`, `!` or `?`, or by a letter that does not begin a complete inert placeholder. Statements are read by line and `;` regardless of quotes, with everything after a line's first `%%` read as comment statements: `click` is refused unless it is a flowchart file link outside a comment, `linkStyle` everywhere, `callback` and `link` in class diagrams, `link`, `links`, `properties` and `details` in sequence diagrams; `classDef` and `style` take one bounded declaration list in every family; `class` and `cssClass` assignments take identifiers where they are assignments. A backslash is refused in the front matter block and on raw CSS statements. The per-family masks for flowchart labels, addresses, placeholders and bidirectional arrows were removed, because the boundary no longer needs them. `renderer.ts` raises the edge limit and lets word spans inherit a label's class font weight and style, which Mermaid otherwise hides with explicit `normal` attributes; this was found while verifying that the admitted declarations are visible. The label-editing refusal message no longer names keywords.
- Implementation (2026-09-12): deliberate reversals are recorded in PLAN-025, plus these found in the PREVIEW-010 and browser suites: addresses in Markdown strings, edge labels, unquoted labels, inline comments, sequence messages, state labels and titles; `data:` text; backslash escape text such as `\x3c` in labels and class notes; a backtick class note with `\n`; the label edit `Click here`; and the browser attack list's `%% classDef evil opacity:0` and `style A fill:red`, replaced by `font-family` and `background` variants that stay refused. A `click` inside a comment, including after a `;`, stays refused as NAV-002 requires.
- Verification (2026-09-12, main checkout at `fd89162`, pinned Bun 1.4.2, project tmux session): the 67 constructs the inventory recorded as valid Mermaid that the policy refused were measured again against the new policy — 44 now render and the 23 the owner kept in the boundary stay refused, with no mismatch. A new multi-family matrix admits 15 ordinary sources from class, state, sequence, ER, Gantt, pie, mindmap, block, requirement, quadrant and flowchart diagrams, each confirmed valid by `mermaid.parse`, including the owner's table with `font-weight:bold` and the MOS diagram with `DATA:`, and refuses 36 boundary constructs spread across those families. The frontend suite passes 428 of 428 with coverage, lint and typecheck pass. Against a built service, class relations with an annotation, a state `<<choice>>`, a sequence diagram with `&`, an address and a Windows path, and the owner's table all rendered with no sanitizer-forbidden element and no page errors; the table header's word spans compute to weight 700 while an unstyled label stays 400, and a flowchart of 1,000 edges reached a live preview in 6.7 s including the host's sanitization and style inlining. The complete browser suite passed 57 of 57 locally, including a new case for the four families with class font weight under the automatic outbound-request audit and a 600-edge diagram beyond the former limit (the browser services cap sources at 8 KiB).
