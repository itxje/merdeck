# UI-001 Implement the diagram editor interface

- **status**: completed
- **priority**: P1
- **owner**: Frontend maintainer
- **createdAt**: 2026-09-07 17:42

## Description

Implement the prototype's responsive file tree, source editor and diagram preview using the required component stack, TanStack file routes and Query. Browse project files, choose individual Markdown diagrams, edit source, save explicitly, zoom/fit and recover from errors. Support English text, light/dark/system themes, accessible controls and keyboard operation.

Keep local drafts separate from refreshed server data. Preserve dirty edits during events, in-flight saves, navigation and disconnects. Handle stale conflicts, deletion and rename without silently discarding edits or recreating deleted files. Enforce strict Mermaid settings, block executable Markdown/unsafe links and verify constrained SVG output.
