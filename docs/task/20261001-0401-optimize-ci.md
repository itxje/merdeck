## Notes

The owner requested CI optimization after v0.19.17 publication. This is Full-tier work with approval granted up front. The observed main and tag workflows each ran the same complete gate; executable and bundle browser suites ran sequentially, and publication records triggered another complete main run. Preserve unrelated project work and the existing publication trust boundary.

## Implementation

Added complete Git-range event classification and distinct documentation, source-only and full native modes. Required verification fails if classification fails. Only full native runs retain checked artifacts, and publishing requires their explicit same-run artifact ID. Split browser/package caches and run complete artifact smoke suites concurrently with isolated browser outputs and awaited cleanup. See [the CI decision](../decisions/2026-10-01-ci-verification-modes.md).

## Verification

Fourteen focused cases pass: explicit path routing, real-tag restrictions, multi-commit pushes, rename/deletion paths, NUL-delimited filenames, new branches, invalid/missing commits, PR merge bases, required workflow status and concurrent failure cleanup. The original behavior failed six mode/concurrency cases before implementation. Git fixtures use the OS temporary filesystem for normal Git semantics; the container's shared workspace does not provide reliable immediate newly initialized repository discovery. Full local and actual hosted acceptance remain pending.
