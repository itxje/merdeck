# NAV-001 Open a linked diagram from the preview

- **status**: completed
- **priority**: P2
- **owner**: Frontend maintainer
- **createdAt**: 2026-09-12

## Description

The project owner keeps an index diagram whose nodes name the sibling diagrams they stand for, using `click A1 "01-system-architecture.mmd"` for each. The policy refuses `click` outright, so the whole index is refused, and even if it rendered, Mermaid's own link would be stripped by the sanitizer. The owner asked for the index to work. Acceptance: a `click` statement naming a project file is accepted and refused in every other form; selecting such a node in the preview opens that file in the workspace; the renderer never produces a usable link or callback of its own; a missing or unreadable target changes nothing except an explicit message; and keyboard users can reach the same targets.

## ActiveForm

Opening a linked diagram from the preview.

## Notes

- Proposal: recorded in [PLAN-021](../plan/PLAN-021.md).
- Approval: the owner reviewed the proposal and said to proceed.
- Implementation (2026-09-12): `source-policy.ts` accepts `click <identifier> "<file>"` where the target is a project-relative path of ordinary segments, no `.` or `..` segment, at most 200 characters, ending in `.mmd`, `.mermaid` or `.md`. A validated statement is masked like a class definition, so `call`, `href`, an address, an extra argument, an unquoted target and the word anywhere outside a flowchart all still refuse the source. The same module exports the resulting map, and the preview marks each named node as a focusable link with an accessible name after it mounts the sanitized diagram, so a pointer click or Enter opens the file through the workspace's existing navigation. The renderer keeps stripping anchors and `href`, so nothing follows a link the renderer produced. A target that is not in the listed tree changes nothing and says so in the preview's note area.
- Verification (2026-09-12, main checkout, pinned Bun 1.4.2, inside the project tmux session): eleven new policy cases accept a two-link index and refuse an address, a parent segment, an absolute path, a foreign extension, a second argument, an unquoted target, `href`, `call`, an empty target and a click outside a flowchart, and a further case pins the extracted map. A new browser case writes two real files, opens the index, finds both nodes marked with their accessible names, activates the missing target from the keyboard and sees only the explanation with the same file still open, then clicks the real target and finds the other file open with its source loaded. `bun run check` passed with 203 backend tests across 9 files and 234 frontend tests across 19 files, and the complete browser suite passed 45 of 45.
