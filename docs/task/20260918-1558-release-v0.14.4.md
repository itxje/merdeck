## Description

Publish patch release `v0.14.4` delivering:
1. An engine and model that stay selectable once a turn settles, instead of locking for the rest of the
   session behind a conversation that outlives `turn.completed`.
2. A panel that settles when the event stream is dropped for good, instead of reporting "Reconnecting..."
   forever against a conversation the service no longer holds.
3. The AI file editor docked open by default, with the operator's choice stored in `merdeck-agent-open`.
4. A larger HTML document preview type scale: 17px body, 14px contents sidebar and `pre`, headings scaled
   with the document type.
