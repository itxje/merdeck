## Description

Implement Hono endpoints over the scoped file service, validated configuration/input, typed safe errors and bounded responses. Bind to loopback by default, require authentication on every binding, and validate Host/Origin. A configured token protects all file and notification routes. Accept the startup token only in login JSON; keep session credentials in cookies/headers and out of URLs/logs.

Implement authenticated bounded tree and selected-document revision polling with typed deletion and explicit truncation. Report relative paths and revisions without leaking absolute roots. Treat rename as delete/create when identity is uncertain. Production serves the built SPA and API without nsl or Vite; document reverse-proxy assumptions.

### Proposal (2026-09-07)

Implement session GET/POST/DELETE and authenticated tree/document/revision/source routes over one injected service. Use fixed-length hashed secret comparison, bounded memory sessions and global login throttling, strict cookie/Host/Origin/CSRF checks, bounded UTF-8 JSON parsing, closed method/query schemas and safe error envelopes. A single global login bucket avoids trusting forwarded client addresses or unbounded per-address state; it may briefly throttle all clients together. No bearer authentication or watcher subsystem is added.

Expose root write eligibility in authenticated SessionStatus without absolute paths or device identifiers. Poll tree snapshots at the advertised interval; selected-file revision reads are fresh and distinguish deleted files. Preserve 409 conflict, 410 deletion and 503 unsupported filesystem semantics, including the documented last comparison/rename and local OS-actor limits.

Serve only an explicit immutable startup map of built web assets, with exact asset lookups, restricted SPA fallback and production security headers. Keep this injectable map usable by future compiled delivery. Production mounts only /api; explicit development stripped mode mounts only domain routes and serves no SPA. Allowed origins supply Host validation; forwarded headers are ignored. If the real development proxy rewrites Host, add only a verified, development-only loopback authority exception tied to its allocated port and explicit Origin.
